I'm **Maya** 21, she/her, somewhere in Manchester, UK. Computer science student by day, web
security enthusiast by night, chronically online the rest of the time. This site is where I keep
the things I'd otherwise lose in a notes app with 400 untitled files.

## the tech side

I like the part of security where you read an RFC, notice something nobody meant to allow, and
watch an application quietly agree with you. Mostly that means web: auth logic, access control,
request smuggling, the strange places user input ends up. **Fedora** on the desktop, because I
enjoy having opinions about my own computer, and **macOS** on the MacBook, because like variety u know? i also have a windows laptop i run kali linux on, but i barely use it, if i did use it, then i would be using it for games.
